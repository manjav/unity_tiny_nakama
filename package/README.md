# Tiny Nakama

A lightweight Nakama client library for Unity.

Tiny Nakama provides a simple and lightweight API for communicating with a Nakama server from Unity projects without requiring the full Nakama Unity SDK.

## Features

- Lightweight Nakama HTTP client
- Authentication and account management
- RPC support
- Leaderboard operations
- Easy integration with Unity projects
- Compatible with Unity Package Manager
- No external dependencies
